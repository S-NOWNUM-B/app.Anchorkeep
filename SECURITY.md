# Политика безопасности

## Поддерживаемые версии

| Версия | Сеть | Поддержка |
|---|---|---|
| MVP (`main`) | Solana Devnet | ✅ |
| Mainnet | — | ❌ не выпускается |

Anchorkeep — учебный MVP. Программа `vault_registry` развёрнута только в **devnet**. Не храни в приложении данные, потеря которых критична.

## Как сообщить об уязвимости

**Не создавай публичный issue.** Используй один из приватных каналов:

1. [GitHub Security Advisory](../../security/advisories/new) — вкладка Security → Report a vulnerability.
2. Email: <mamayev.stas@gmail.com>, тема `[Anchorkeep security]`.

Укажи:

- что затронуто (модуль, файл, инструкция программы);
- шаги воспроизведения или PoC;
- оценку последствий;
- версию/коммит и платформу (Android / Windows).

Ответим в течение 7 дней. Просим не раскрывать детали публично до выпуска исправления.

## В scope

От чего проект защищает и от чего нет — [`docs/THREAT_MODEL.md`](docs/THREAT_MODEL.md).

| Область | Примеры |
|---|---|
| Криптография (`core/crypto`) | переиспользование nonce, слабый ГСЧ, ошибки KDF/AEAD, обход проверки AAD |
| Формат vault (`.akv` / `.akbackup`) | подмена заголовка без ошибки расшифровки, порча файла при неатомарной записи, rollback без статуса Outdated |
| Утечки секретов | мастер-пароль, ключи или расшифрованные данные на диске, в логах, буфере обмена дольше 30 с, краш-репортах |
| Программа `vault_registry` | обход проверки `owner`, `commit_version` с версией не больше текущей (обход `VersionMismatch`, ADR 0006), запись чужого PDA, утечка данных on-chain сверх pubkey / `vault_id` / версии / хеша |
| Проверка бэкапа (F9) | ложный статус Verified для устаревшего или изменённого файла |
| Автоблокировка | сейф остаётся разблокированным после таймаута или сворачивания |

## Вне scope

- Devnet SOL, airdrop и всё, что связано с ценностью devnet-токенов.
- Известные trade-offs из [`docs/PRD.md`](docs/PRD.md):
  - on-chain видно, **когда** пользователь заверял версии (метаданные активности);
  - потеря мастер-пароля = потеря данных, восстановления нет;
  - для F8/F9 нужен интернет.
- Невозможность гарантированно обнулить память в Dart (ограничение платформы; смягчаем минимальным временем жизни ключей).
- Атаки, требующие root/админ-доступа или вредоносного ПО на устройстве пользователя.
- iOS / macOS / Linux — не поддерживаемые платформы MVP.
- Отсутствие защитных заголовков, rate limiting и т. п. — у проекта нет сервера.
