# Anchorkeep — PRD (MVP, 8 недель)

## Проблема
Менеджеры паролей либо облачные (доверие к чужому серверу), либо локальные — но тогда бэкап можно подменить или откатить на старую версию, и пользователь этого не заметит. AES-GCM защищает от порчи данных, но **не** от отката к старому валидному бэкапу (rollback).

## Решение
Локальный зашифрованный сейф без регистрации и сервера. При каждом бэкапе SHA-256 зашифрованного файла и номер версии записываются в Solana. При восстановлении приложение сверяет бэкап с on-chain записью и говорит: «это последняя подлинная версия» / «устаревшая версия» / «неизвестный файл».

Секреты в блокчейн не попадают и через блокчейн не восстанавливаются.

## Целевой пользователь
Технически грамотный человек, который не хочет хранить пароли в облаке, но переносит данные между телефоном и ПК через файл.

## Scope MVP

### Must have
| # | Фича | Критерий готовности |
|---|------|---------------------|
| F1 | Создание сейфа и мастер-пароль | Онбординг, проверка сложности пароля, предупреждение «пароль не восстановить» |
| F2 | Разблокировка / блокировка | Неверный пароль → ошибка без утечки деталей; ручная блокировка |
| F3 | Пароли | CRUD: название, логин, пароль, URL, заметка; генератор паролей; копирование |
| F4 | Заметки | CRUD зашифрованных текстовых заметок |
| F5 | Поиск | По названию/URL среди паролей и заметок |
| F6 | Бэкап | Экспорт зашифрованного файла `.akbackup` через file_picker |
| F7 | Восстановление | Импорт бэкапа + ввод мастер-пароля бэкапа |
| F8 | Anchoring | Кнопка «Заверить версию»: регистрация хеша в Solana Devnet |
| F9 | Проверка | При импорте и по кнопке: статус Verified / Outdated / Unknown |
| F10 | Безопасность UX | Автоблокировка по таймауту (по умолчанию 5 мин) и при сворачивании; очистка буфера через 30 с |

### Should have (если успеваем, неделя 7)
- Смена мастер-пароля (перешифровка только ключа сейфа)
- Разблокировка биометрией на Android
- Secure Files: вложения до 10 МБ

### Out of scope (явно НЕ делаем)
- Синхронизация, облако, аккаунты, сервер
- Phantom / внешние кошельки (только встроенный devnet-keypair)
- Mainnet, токены, NFT
- Автозаполнение в браузерах и системе
- iOS / macOS / Linux как поддерживаемые платформы
- Шаринг записей между пользователями

## Платформы
Android (API 26+) и Windows 10+. Единая кодовая база Flutter, адаптивный layout (mobile / desktop).

## Метрики демо
- Сценарий «телефон → бэкап → ПК → восстановление → Verified» проходит за < 2 мин.
- Сценарий «подсунули старый бэкап» → приложение показывает **Outdated**.
- Разблокировка ≤ 1.5 с на средне-бюджетном Android.

## Известные trade-offs (говорим на защите)
- On-chain видно, **когда** пользователь заверял версии (метаданные активности). Содержимое — нет.
- Нужен интернет и devnet-SOL только для F8/F9; всё остальное офлайн.
- Потеря мастер-пароля = потеря данных. Это осознанно.
