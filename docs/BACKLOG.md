# Anchorkeep — бэклог (8 недель, 3 человека)

Формат готов для импорта в Linear: Project **Anchorkeep MVP**, milestones = недели, labels = роли.

## Роли
- **Core** — криптография, формат vault, хранение, безопасность
- **UI** — Flutter-экраны, дизайн-система, адаптивность, навигация
- **Chain** — Anchor-программа, Dart-адаптер Solana, CI программы

Оценки: S ≈ 0.5 дня, M ≈ 1–2 дня, L ≈ 3–4 дня.
