# 0001. Лицензия GPL-3.0-or-later

- **Статус:** Accepted
- **Дата:** 2026-10-21
- **Задача:** AK-01

## Контекст

Anchorkeep — открытый проект команды из трёх человек. Команда хочет, чтобы код можно было свободно использовать, изучать и дорабатывать, но чтобы его нельзя было взять, закрыть и превратить в проприетарный продукт. Проект также планируется подавать на гранты и хакатоны, где обычно требуется OSI-одобренная лицензия.

У приложения нет сервера: оно работает офлайн, сеть нужна только для обращения к Solana Devnet.

## Решение

Лицензия проекта — **GPL-3.0-or-later**. Полный текст — в [`LICENSE`](../../LICENSE). Вклад принимается под той же лицензией, без CLA.

## Альтернативы

| Вариант | Почему отвергнут |
|---|---|
| MIT | Разрешает закрыть производную работу — противоречит цели |
| MIT + GPL (dual) | Любой выберет MIT, копилефт теряет смысл |
| AGPL-3.0 | Сетевой пункт защищает от SaaS-использования, а у офлайн-приложения без сервера его нет — лишнее ограничение без пользы |
| PolyForm Noncommercial | Не OSI-лицензия, не считается open source — мешает грантам и хакатонам |

## Последствия

- GPL не запрещает продажу, но любая распространяемая производная работа должна открывать исходники под GPL-3.0 (или более поздней версией).
- Зависимости под MIT, BSD и Apache-2.0 совместимы с GPL-3.0; новые зависимости с другой лицензией проверяем перед добавлением.
- Файлы можно помечать заголовком `SPDX-License-Identifier: GPL-3.0-or-later`.
- «or-later» позволяет перейти на будущую версию GPL без согласования со всеми авторами.
