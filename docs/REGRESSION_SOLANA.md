## Проверка бэкапа: статусы по ветвям

Источник: `app/test/core/solana/backup_verification_test.dart`. Статусы — enum `AnchorStatus` (`app/lib/core/solana/backup_verification.dart`).

| Ситуация | Статус в коде | Тест | Текст в UI (`backup_workspace.dart`) |
|---|---|---|---|
| Файл совпал с заверенным | `verified` | автотест | «Файл подтверждён» |
| Файл старее заверенной версии (старый бэкап) | `outdated` | автотест | «Бэкап устарел» |
| Хеш не совпал, версия не старше (не заверен или изменён) | `unknown` | автотест | «Версия не подтверждена» |
| Та же версия, другие байты (подмена) | `unknown` | автотест | «Версия не подтверждена» |
| Сейф ещё не заверяли | `notAnchored` | автотест | «Нет записи о заверении» |
| Нет сети или RPC не ответил | `offline` | автотест (по видам ошибок) | «Сеть недоступна» |
| По адресу лежит не `VaultRecord` | `unknown` | автотест | «Версия не подтверждена» |
| Файл после смены пароля, ещё не заверенный | `unknown` | автотест | «Версия не подтверждена» |
| В чтение уходят `owner` и `vaultId` из файла | — | автотест | — |
| Не файл сейфа | `FormatException`, сеть не вызывается | автотест | — |

Смысл для защиты: `unknown` — не «подделка доказана», а «совпадения с записью нет». Отсюда текст «Версия не подтверждена», а не «Подделка».

## Заверение (anchoring): исходы

Источник: `app/test/core/solana/anchoring_test.dart`.

| Ситуация | Результат в коде | Тест |
